# FinTech Operations Dashboard

## Overview

This dashboard provides a visual overview of FinTech payment operations performance, focusing on ticket volume, payment failures, SLA compliance, resolution time, and operational workload.

## Dashboard KPIs

- Total Tickets
- SLA Compliance
- Average Resolution Time
- Open Tickets
- Failed Payments

## Dashboard Visualizations

### 1. Payment Failure Trend

Shows payment failure cases across the selected dates to identify payment-related operational issues.

### 2. Operations Workload by Issue

Shows the number of tickets across different issue categories, helping identify the highest-volume operational problems.

### 3. SLA Compliance by Team

Compares SLA performance across assigned teams to identify differences in operational efficiency.

### 4. Average Resolution by Issue

Shows the average time required to resolve different types of operational issues.
